# 01. 요구사항 명세

## 1. 목적

투자자·리서치 담당자가 **시장의 주도 섹터/테마가 시간에 따라 어떻게 교체되어 왔는지**를 한 화면에서 파악하도록 한다.
단일 기간의 순위표가 아니라 **순위의 이동 경로(범프 차트)** 를 1차 산출물로 삼는다.

## 2. 사용자 시나리오

| # | 시나리오 | 필요한 산출물 |
| --- | --- | --- |
| S-1 | 최근 26주 동안 어떤 섹터가 상위권을 유지했는지 본다 | 섹터별 기간 수익률·순위 시계열 |
| S-2 | 특정 주에 시장이 크게 하락했을 때, 어느 섹터가 하락을 주도했는지 본다 | 섹터별 시장 기여도(가중 기여) |
| S-3 | 1위 섹터의 상승이 소수 대형주 때문인지 확인한다 | 섹터 내 종목별 기여도, 집중도 지표 |
| S-4 | 주 단위 관찰을 월 단위로 전환해 추세를 확인한다 | 동일 지표의 월 단위 재집계 |
| S-5 | 한국과 미국의 섹터 로테이션을 각각 비교한다 | 시장별 독립 조회 |

## 3. 조회 대상 (Universe)

유니버스는 **기간 가중치 산정 기준일(t-1 기간 말 거래일)** 시점 기준으로 확정한다.

### 3.1 `KR_COMMON`

- 거래소: KOSPI, KOSDAQ
- 증권 종류: **보통주만** 포함
- 제외: 우선주, ETF, ETN, ELW, REITs, SPAC, 인프라/투자회사, 뮤추얼펀드, **외국기업 전체(외국주권·DR)** 등 보통주가 아닌 모든 종목. 판정 규칙과 실제 제외 건수는 [07 §7.1](07-price-ingestion.md#71-종목-마스터와-유니버스)에 있다
- 상장 상태: 기준일에 정상 상장 상태(관리종목·거래정지는 포함하되 상태 플래그로 구분)
- 통화: KRW

### 3.2 `US_SP500`

- S&P 500 **구성종목(as-of 기준일)**
- 구성종목 편입/편출 이력을 보유하여 과거 기간 조회 시 **당시 구성종목**으로 계산한다(생존 편향 방지)
- 동일 기업 복수 클래스 종목(예: 의결권 클래스 분리)은 지수 구성에 포함된 각 라인을 개별 종목으로 취급
- 통화: USD

### 3.3 공통 원칙

- 두 유니버스는 **서로 합산하지 않는다.** 통화 환산 및 한·미 통합 수익률은 제공하지 않는다.
- 유니버스 편입 여부는 일자별 이력으로 관리한다.

## 4. 분류 체계 (Classification Scheme)

분류 정보는 외부 벤더 실시간 연동이 아니라 **자체 보유 매핑 테이블로 제공**한다.

| 스킴 코드 | 시장 | 유형 | 배타성 | 설명 |
| --- | --- | --- | --- | --- |
| `WI26` | KR | SECTOR | 배타(1종목 1섹터) | WI26 산업 분류에 준함 |
| `GICS` | US | SECTOR | 배타(1종목 1섹터) | GICS 섹터 레벨(11개)에 준함 |
| `THEME_*` | KR/US | THEME | 비배타(1종목 N테마) | 자체 정의 테마 그룹 |

- 섹터 스킴은 **배타적**이다. 동일 시점에 한 종목이 두 섹터에 속할 수 없다.
- 테마 스킴은 **비배타적**이다. 한 종목이 여러 테마에 속할 수 있으며, 이 경우 테마별 수익률은 각각 독립적으로 계산된다(합이 시장 수익률이 되지 않음 → 기여도 분해는 배타 스킴에서만 제공).
- 매핑은 **유효기간(valid_from / valid_to)** 을 갖는 이력 테이블이다. 과거 기간 계산 시 그 시점의 매핑을 사용한다.
- 분류 체계 자체의 개편(코드 신설/통합)도 이력으로 관리한다.

## 5. 기간 체계 (Period)

| 코드 | 단위 | 식별자 형식 | 경계 |
| --- | --- | --- | --- |
| `W` | ISO Week | `YYYY-Www` (예: `2026-W03`) | 월요일 ~ 일요일, ISO-8601 week-year 기준 |
| `M` | Month | `YYYY-MM` (예: `2026-01`) | 역월(calendar month) 1일 ~ 말일 |

- **화면 기본값은 `W`(주)** 이다.
- 기간의 실제 계산 기준일은 캘린더 경계가 아니라 **해당 기간 내 마지막 거래일**이다. 거래일 캘린더는 시장별(KR/US)로 별도 관리한다.
- 거래일이 하루도 없는 기간(장기 연휴 주 등)은 기간 자체를 생성하지 않는다.
- ISO Week는 연초/연말에 week-year가 역월 연도와 어긋날 수 있다(예: `2027-W01`이 2026-12-28 시작). 정렬·조회 키는 반드시 ISO week-year 기준으로 처리한다.
- 진행 중인 기간(아직 종료되지 않은 주/월)은 **잠정치(provisional)** 로 계산하고 플래그를 부여한다. 기준 종가는 최신 거래일 종가를 사용한다.

| 지표 | 요약 | 상세 |

| 섹터/테마 수익률 | **직전 기간 말 시가총액 가중** 평균 | [03](03-metrics-spec.md#4-그룹섹터테마-수익률) |
| 시장 수익률 | 유니버스 전체를 하나의 그룹으로 본 값 | [03](03-metrics-spec.md#5-시장-수익률) |
| 섹터 순위 | 기간별 수익률 내림차순 순위 | [03](03-metrics-spec.md#6-순위) |
| 시장 기여도 | 직전 기간 말 시장 내 섹터 비중 × 섹터 수익률 | [03](03-metrics-spec.md#7-시장-기여도-분해) |
| 종목 기여도 | 섹터 내 비중 × 종목 수익률 | [03](03-metrics-spec.md#8-섹터-내-종목-기여도) |

## 7. 화면 요구사항 요약

- 메인: **섹터/테마 순위 범프 차트** (x=기간, y=순위, 1위가 상단)
- 보조 1: 선택 기간의 섹터별 수익률/기여도 막대
- 보조 2: 섹터 선택 시 **종목 기여도 드릴다운 + 집중도 카드**
- 컨트롤: 시장(유니버스), 분류 스킴, 기간 단위(W/M, 기본 W), 조회 구간, 표시 섹터 수
- 상세는 [06-ui-spec.md](06-ui-spec.md)

## 8. 범위 경계 (Out of Scope)

이번 범위에 포함하지 않는다. 데이터 모델은 후속 확장을 막지 않도록 설계하되, 기능으로 제공하지 않는다.

- 실시간/장중 시세 및 인트라데이 수익률
- 한·미 통합 수익률, 환율 환산, 공통 통화 기준 비교
- 종목 추천, 매매 신호, 포트폴리오 백테스트/성과 귀속(attribution) 리포트
- 배당 재투자 총수익(Total Return) 기반 지표 — 기본은 **수정주가 기반 가격 수익률**
- 리스크 지표(변동성, 베타, 샤프 등)
- 사용자별 커스텀 테마 편집 UI (테마 매핑은 데이터 적재로 공급)

## 9. 용어

| 용어 | 정의 |
| --- | --- |
| 유니버스(Universe) | 계산 대상 종목 집합. `KR_COMMON`, `US_SP500` |
| 스킴(Scheme) | 분류 체계. `WI26`, `GICS`, `THEME_*` |
| 그룹(Group) | 스킴에 속한 개별 섹터 또는 테마 |
| 기간(Period) | 계산 단위. `W` 또는 `M` |
| 기준일(Base Date) | 가중치 산정일. 직전 기간(t-1)의 마지막 거래일 |
| 종료일(End Date) | 대상 기간(t)의 마지막 거래일 |
| 기여도(Contribution) | 상위 집합의 수익률에 대한 하위 구성요소의 가산적 분해값 |
| 잠정치(Provisional) | 아직 종료되지 않은 기간에 대해 최신 거래일 기준으로 계산한 값 |
