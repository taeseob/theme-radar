## 2. 컨트롤 바

| 컨트롤 | 기본값 | 옵션 | 비고 |
| --- | --- | --- | --- |
| 시장(유니버스) | 한국 | 한국 / 미국 | 변경 시 분류 스킴이 해당 시장의 것으로 자동 전환 |
| 분류 체계 | 시장의 **가장 잘게 나눈 배타 스킴** (KR: WI26 소분류 48 / US: GICS 산업 74) | 시장별 등록 스킴. 라벨에 그룹 수를 함께 적는다 | 굵게 보려면 대분류·섹터 스킴으로 바꾼다. 고른 값은 URL에 남는다. 테마 스킴은 그룹 하위에 표시 |
| 기간 단위 | **주(W)** | 주 / 월 | 세그먼트 토글 |
| 조회 구간 | 최근 26기간 | 13 / 26 / 52 / 104 기간, 사용자 지정 | 단위 전환 시 기간 수 유지(주 26 → 월 26) |
| 표시 섹터 수 | 전체 | 전체 / 상위 5 / 상위 10 | 구간 내 **최고 순위** 기준 필터 |
| 이동평균 기간 | 5 | 2 ~ 52 기간 (주 단위면 주, 월 단위면 개월) | 화면 전체가 같은 `N`을 쓴다: 순위 기준([§3.5](#35-이동평균-기준)) · 스냅샷 이격도([§4](#4-기간-스냅샷-패널)) · 시가총액 차트([§5.4](#54-섹터-시가총액-차트)) |

- 모든 컨트롤 상태는 URL 쿼리스트링에 반영해 **화면 공유·북마크**가 가능하게 한다.
  `?universe=KR_COMMON&scheme=WI26&period=W&range=26&top=10&basis=ma&above=1&focus=WI620&mode=rank&view=chart&group=WI620&pid=2026-W36&cap=candle&ma=1&ma_n=5&side=WI620&side_ma=1&side_ma_n=8`
- 구간은 기간 수(`range`)로 두고, 화면이 `/meta/periods?last=N`으로 그 구간의 `from`/`to`를 받아 API에 넘긴다. 기간 단위를 바꿔도 기간 수가 유지된다. 이동평균에 쓸 앞 기간(`N`기간)을 같은 호출에서 함께 받아 두고, 시가총액 차트도 그 목록을 쓴다.
- 시장과 분류 스킴의 조합이 불일치하면 컨트롤 단계에서 차단한다(API 400을 화면에서 유발하지 않는다).

## 3. 범프 차트 (메인)

### 3.1 렌더링 규칙

| 항목 | 규칙 |
| --- | --- |
| x축 | 기간 (`period_id`), 좌 → 우 시간순. 라벨은 `W36` / `26-09` 축약, 연도 변경 지점에만 연도 표기. 차트 폭은 사용자가 바꾸므로([§3.6](#36-시장-지수와-섹터-캔들)) 자리가 좁아지면 라벨을 솎는다 |
| y축 | 순위. **1위가 최상단**(축 반전). 눈금은 1, 5, 10, …, 최대 순위 |
| 선 | 그룹당 1개. 색상은 `meta/groups`의 `color` 고정값 |
| 점 | 각 기간의 순위 위치. 반지름은 고정 |
| 결측 | 해당 기간에 그룹이 없으면 점을 찍지 않고 **선을 끊는다** (보간하지 않는다) |
| 잠정 기간 | 아직 끝나지 않은 기간도 다른 구간과 **같은 실선**으로 잇는다. 차트에서는 구분하지 않고, 기간의 실제 범위는 툴팁의 기준일·종료일로 읽는다 |
| 라벨 | 차트 오른쪽 끝에 그룹명 표시. 겹치면 수직 충돌 회피 후 초과분은 생략. 순위 모드는 값이 고르게 퍼져 전부 표시되고, 수익률 모드는 값이 몰리는 만큼 줄어든다. 생략된 섹터는 범례로 식별한다 |

### 3.2 상호작용

| 동작 | 결과 |
| --- | --- |
| 선/라벨 hover | 해당 선 강조(두께 증가), 나머지 선 불투명도 20%로 감쇠. **마우스와 같은 기간**의 툴팁 표시 (§3.3) |
| 점 hover | 툴팁 표시 (§3.3) |
| 선 클릭 | 해당 섹터 **고정 선택**. 드릴다운 패널 열림. 다시 클릭하면 해제 |
| 점 클릭 | 해당 섹터 + 해당 기간으로 드릴다운 패널 열림 |
| 더블클릭 | 해당 섹터를 **강조**에 넣고 뺀다 (아래) |
| 범례 클릭 | 해당 섹터 표시/숨김 토글 |
| x축 드래그 | 구간 확대(선택). 더블클릭으로 초기화 |
| 차트 높이 | 차트 오른쪽 아래 모서리를 끌어 바꾼다. 브라우저에 저장해 다음에 열 때도 유지한다 |

- ECharts 툴팁은 데이터 점에만 붙어 선 위에서는 뜨지 않는다. 상자를 직접 그려 점과 선을 같게 다룬다.
- 상자는 **마우스 포인터 왼쪽**에 붙인다. 왼쪽 자리가 좁으면 오른쪽으로 넘긴다.
- 선이 점 위를 덮어 ECharts는 점 클릭을 따로 알려 주지 않는다. 마우스와 점 사이 거리(8px 이내)로 점 클릭과 선 클릭을 가른다.

**강조** (`focus=WI620,WI500`)

- 기본은 강조가 없는 상태이고, 스킴의 모든 그룹이 또렷하다.
- 섹터를 더블클릭하면 그 섹터가 강조에 들어가고 **강조에 없는 섹터는 옅어진다**(불투명도 15%). 이어서 다른 섹터를 더블클릭하면 함께 강조한다.
- 강조된 섹터를 다시 더블클릭하면 강조에서 빠진다. 마지막 하나가 빠지면 다시 전부 또렷한 처음 상태다.
- 옅은 선도 그대로 누를 수 있다. 강조를 늘리려면 옅은 선을 더블클릭한다.
- 강조가 있으면 **끝단 라벨은 강조한 섹터에만** 붙인다. 옅은 선의 이름까지 적으면 강조가 묻힌다.
- 강조가 하나라도 있으면 차트 아래에 한 번에 푸는 단추를 둔다.
- 더블클릭에도 클릭 이벤트가 먼저 두 번 오므로, 한 번 클릭의 처리(섹터 선택)를 0.26초 미뤄 두고 더블클릭이 오면 취소한다. 빈자리 더블클릭은 그대로 구간 확대를 되돌린다.

### 3.3 툴팁

```
반도체 · 2026-W36
2026-08-31 ~ 2026-09-06
────────────────────────────────
순위        1위  (전 기간 4위, ▲3)
수익률      +6.15%
시장 비중   27.48%
시장 기여   +169bp   (시장 +241bp의 70%)
구성종목    118종목
상위1 기여  71%
기준일 2026-08-28 → 2026-09-04
```

- 기간 표기는 `base_date + 1영업일 ~ end_date`가 아니라 **`cal_start ~ cal_end`(캘린더 경계)** 를 쓰고, 실제 기준일/종료일은 하단에 작게 병기한다. 캘린더 경계는 `/meta/periods` 응답에서 가져온다.
- 시장 수익률이 ±5bp 이내면 "시장 기여" 줄의 괄호 안 비율을 표시하지 않는다.
- 동일가중 수익률과 상승 종목 수는 `/sectors/ranks`가 싣지 않는다. 툴팁 하나 때문에 범프 차트 응답을 키우지 않고, 두 값은 스냅샷 행과 드릴다운에서 본다.

### 3.4 순위의 한계 안내

순위 차트만으로는 "1위 섹터가 실제로 올랐는지"를 알 수 없다(전 섹터 하락 시에도 1위는 존재). 따라서:

- 차트 우상단에 **해당 구간 시장 수익률 요약**을 상시 표시한다.
- 각 점의 색 채도 또는 점 테두리로 수익률 부호를 구분한다(양수: 실선 테두리, 음수: 파선 테두리).
- 토글로 **"순위" ↔ "수익률"** y축 전환을 제공한다(수익률 모드는 범프가 아닌 일반 선 차트).

### 3.5 이동평균 기준

순위와 값의 **기준**을 두 가지로 둔다. 축 토글(순위 ↔ 수익률)과는 따로 고르며, 둘을 곱한 네 가지 화면이 나온다.

| 기준 | URL | 값 | 순위 |
| --- | --- | --- | --- |
| 기간 | `basis=period` (기본) | 기간 수익률 | `/sectors/ranks`의 `rank` |
| 이동평균 | `basis=ma` | `N`기간 이동평균의 **상승률** | 그 상승률의 순위 |

- 값은 [03 §14.4](03-metrics-spec.md#144-이동평균-상승률과-이격도)이고, 화면이 `/sectors/market-caps`([05 §3.3](05-api-spec.md#33-get-sectorsmarket-caps))의 기간 말 시총으로 계산한다. 서버에 두지 않는다.
- 기간 수익률이 한 기간의 등락을 보는 값이라면, 이동평균 상승률은 **섹터가 어느 방향으로 흐르는지**를 본다. 시총 기준이라 상장·폐지 같은 가격 외 변화가 들어간다([03 §14](03-metrics-spec.md#14-섹터-시가총액)).
- 이동평균 기준에서는 축 토글의 "수익률"을 **"상승률"** 로 적는다.
- 상승률을 낼 앞 기간이 모자라 값이 없는 기간은 점을 찍지 않는다. 구간 첫 기간부터 선이 이어지도록 앞 `N`기간을 더 받는다.
- 표 대체 표현([§8](#8-접근성-및-반응형))도 같은 값을 쓰고, 제목에 기준을 적는다.

**이동평균 위만 보기** (`above=1`, 이동평균 기준에서만 보인다)

- **선택 기간**(`pid`, 기본 최신 기간)의 이격도가 100을 넘는 섹터만 남긴다. 나머지는 "표시 기준 밖 N개"로 센다.
- 선택 기간을 바꾸면 그 기간 기준으로 다시 거른다. 남는 섹터가 없으면 차트 자리에 안내 문구를 둔다.

### 3.6 시장 지수와 섹터 캔들

범프 차트 오른쪽에 **시장 배경**을 둔다. 순위는 상대적인 값이라 시장 자체가 오르는 중인지 내리는 중인지는 알려 주지 않는다([§3.4](#34-순위의-한계-안내)).

| 항목 | 규칙 |
| --- | --- |
| 자리 | 범프 차트와 같은 행의 오른쪽. 기본 320px이고 **가운데 손잡이를 끌어 너비를 바꾼다.** 1280px 미만에서는 차트 아래로 내려가고 손잡이는 감춘다. 높이는 범프 차트를 따라간다 |
| 너비 조절 | 손잡이를 끌면 잡은 자리가 포인터를 따라온다. 패널은 220px 아래로 줄지 않고, 순위 차트에는 360px를 남긴다. 손잡이는 분리선(`separator`)이라 ←/→ 키로 24px씩 옮기고, 더블클릭하면 기본 320px로 돌아간다. 정한 너비는 브라우저에 저장해 다음에 열 때도 유지한다(차트 높이와 같은 규칙, [§3.2](#32-상호작용)) |
| 지수 차트 | 늘 보인다. KR `KOSPI`, US `S&P 500`. 기간 단위 캔들이며 상승·하락 색은 스냅샷 막대와 같은 시장 관행 |
| 섹터 차트 | 섹터를 고르면 지수 차트 **위에** 그 섹터의 시가총액 캔들을 함께 둔다. 고르지 않으면(`지수만`) 지수 차트가 자리를 다 쓴다 |
| 섹터 선택 | 이 패널만의 선택이다(`side`). 범프 차트 클릭이나 드릴다운의 섹터(`group`)와 **연동하지 않는다.** 두 섹터를 나란히 보려면 따로 골라야 하기 때문이다 |
| 이동평균 | 이 패널만의 설정이다(`side_ma`, `side_ma_n`). 켜면 두 차트에 같은 기간 수의 이동평균선을 그린다 |
| 구간 | 범프 차트와 같다. 이동평균에 쓸 앞 기간은 화면 공통 이동평균 기간과 이 패널 기간 중 **긴 쪽**에 맞춰 받는다 |
| 축·툴팁 | 좁은 차트라 범례를 두지 않고 소제목이 이름을 대신한다. 눈금은 3단이고 x축 라벨은 자동으로 솎는다. 툴팁은 드릴다운 시가총액 차트와 같은 내용이되, 지수는 구성종목 수 대신 거래일 수를 적는다 |
| 세로선 | 두 차트가 함께 있으면 **세로선은 양쪽에 함께 선다.** 같은 기간 축을 쓰므로 섹터의 어느 주가 지수의 어느 주인지 눈으로 잇는다. 상자는 포인터가 있는 차트에만 띄운다. 둘 다 띄우면 같은 값을 두 번 읽게 된다 |
| 데이터 없음 | 그 차트 자리에만 안내 문구를 둔다. 지수 일봉을 아직 받지 않았으면 실행할 명령을 알려 준다 |

- 지수 값은 [03 §15](03-metrics-spec.md#15-시장-지수), 데이터는 `/market/index`([05 §4.2](05-api-spec.md#42-get-marketindex))다.
- 지수는 우리가 계산한 유니버스 수익률이 아니라 거래소 공식 지수다. 두 값을 한 축에 섞지 않는다.

## 4. 기간 스냅샷 패널

- 범프 차트에서 선택된 기간(기본: 최신 기간)의 섹터 전체 목록.
- 열 순서: 섹터명 · 수익률 막대 · 수익률 · 시총 비중 · 시장 기여(bp) · 시장 대비 · 이격도 · 순위 변동 · 집중도 배지.
- 값 행과 **같은 격자의 머리글 행**을 둬 각 열이 무엇인지 적는다. 값은 한 칸에 하나만 둔다. 한 칸에 둘을 이어 쓰면 폭이 행마다 달라져 숫자가 어긋난다.
- 정렬 기준은 컨트롤(수익률 / 기여도 / 시총 비중 / 이격도)과 **머리글 열 클릭** 둘 다로 바꾼다. 현재 기준인 열에 `▼`를 붙인다. 정렬 가능한 열은 정렬 기준과 1:1로 맞춘다.
- **이격도** 열은 선택 기간의 `기간 말 시총 ÷ N기간 이동평균 × 100`이다([03 §14.4](03-metrics-spec.md#144-이동평균-상승률과-이격도)). 100보다 크면 이동평균 위이고, 상승/하락과 같은 색을 쓴다. 이 값과 정렬은 **화면이 맡는다**. `/sectors/returns`의 `sort`에는 없으므로 기본 정렬로 받아 화면에서 다시 세운다. 값이 없는 섹터(이동평균을 낼 기간이 모자라거나 섹터 시총이 없는 경우)는 빈칸으로 두고 뒤로 보낸다.
- 막대는 **0을 중심으로 양방향**(diverging)으로 그린다. 상승/하락 색은 시장 관행에 따르되 설정 가능하게 한다(KR 기본: 상승 적색 / 하락 청색, US 기본: 상승 녹색 / 하락 적색).
- 기준 0 선은 행 사이 여백까지 이어 붙여 **열을 가르는 한 줄**로 보이게 한다. 머리글의 같은 칸에 왼쪽 끝(−최대) · `0` · 오른쪽 끝(+최대)을 적는다. 최대는 그 기간 표시 섹터의 `|수익률|` 최댓값이며, 막대의 반폭이 이 값에 해당한다.
- 0 선이 세로로 이어지려면 **막대 칸의 폭이 행마다 같아야** 한다. 그래서 막대 칸을 뺀 모든 칸을 고정 폭으로 둔다. 마지막 배지 칸을 내용에 맞춰 늘리면 배지 수만큼 막대 칸이 밀려 0의 위치가 행마다 달라진다.
- 기여도는 `bp` 정수로 표시한다. 비율(`contribution_share`)은 "시장 대비" 열에 두며, `null`이거나 **0.5% 미만이거나 음수이면 빈칸으로 둔다**. 섹터가 시장과 반대로 움직이면 이 비율이 음수가 되는데, "시장 수익률의 −22%"는 읽히지 않는 수치다.
- `UNMAPPED` 행은 시총 비중이 0.1% 이상일 때만 표시하고 회색 처리한다.

## 5. 드릴다운 패널

섹터 선택 시 열린다. **"이 성과가 소수 종목에 집중되어 있는가"** 를 한 눈에 보여주는 것이 목적이다.

### 5.1 집중도 카드

| 카드 | 값 | 보조 표기 |
| --- | --- | --- |
| 상위 1종목 기여 | `top1_contrib_share` | 양의 기여 총합 대비 비율임을 툴팁으로 안내 |
| 상위 3종목 기여 | `top3_contrib_share` | — |
| 유효 종목 수 | `effective_n` / `member_cnt` | "실질 N종목" |
| 상승 종목 비율 | `up_cnt` / `member_cnt` | 게이지 |
| 대형주 스프레드 | `cap_weight_spread` | 시총가중 − 동일가중, %p |

배지 판정 기준은 [03 §9.5](03-metrics-spec.md#95-판정-가이드-ui-배지용).

### 5.2 종목 기여 차트

- 가로 막대. x = `contribution_in_group`(bp), y = 종목.
- 기본 상위 10 + 하위 10 + `기타 N종목` 합산 행(`/sectors/{group}/breakdown?side=both&limit=10`).
- 각 행에 `weight_in_group`(섹터 내 비중)과 `return`(개별 수익률)을 병기한다. **비중이 커서 기여가 큰 것**과 **수익률이 높아서 기여가 큰 것**을 구분할 수 있어야 한다.
- 막대 합계가 섹터 수익률과 일치함을 하단에 명시한다: `합계 = 섹터 수익률 +6.15%`.

### 5.3 섹터 시계열

- 선택 섹터의 수익률·순위·`top1_contrib_share` 스파크라인 3종.
- `top1_contrib_share` 스파크라인은 "이 섹터가 원래 집중적인지, 이번 기간에만 쏠렸는지"를 판별하는 근거가 된다.

### 5.4 섹터 시가총액 차트

선택 섹터의 시가총액 추이. 조회 구간은 범프 차트와 같다. 값의 정의는 [03 §14](03-metrics-spec.md#14-섹터-시가총액), 데이터는 `/sectors/{group}/market-cap`([05 §5.3](05-api-spec.md#53-get-sectorsgroup_codemarket-cap))이다.

| 컨트롤 | 기본값 | 옵션 | URL |
| --- | --- | --- | --- |
| 차트 모양 | 선 | **선**: 기간 말 시가총액을 잇는다 / **캔들**: 일별 시가총액으로 만든 기간 시가·고가·저가·종가 | `cap=line` / `cap=candle` |
| 이동평균 표시 | 끔 | 켬 / 끔 | `ma=1` |

이동평균의 기간 수는 화면 공통 컨트롤이다([§2](#2-컨트롤-바)).

| 항목 | 규칙 |
| --- | --- |
| y축 | 시가총액. 0에서 시작하지 않는다(값이 0에서 멀어 움직임이 보이지 않는다). 눈금은 KR `600조`, US `$1,250B` |
| 선 | 섹터 색(`meta/groups`의 `color`), 2px. 결측 기간에서 끊는다 |
| 캔들 | 상승·하락 색은 스냅샷 막대와 같은 시장 관행(KR 상승 적색·하락 청색, US 상승 녹색·하락 적색). 시가가 직전 기간 종가라 캔들끼리 이어진다 |
| 이동평균 | 기간 말 값의 단순 평균을 **화면이 계산한다.** DB와 API에 두지 않는다. 구간 첫 기간부터 선이 이어지도록 구간 앞 `N − 1`기간을 더 받아 계산하고, 보이는 구간만 그린다. 중립 잉크색 2px 선 |
| 범례 | 이동평균을 켜서 계열이 둘일 때만 둔다 |
| 선택 기간 | 드릴다운이 보고 있는 기간(`pid`)에 세로 실선 |
| 툴팁 | 십자선이 가까운 기간을 잡는다. 기간·캘린더 경계, (캔들이면 시가·고가·저가) 종가와 직전 기간 대비 변화율, 이동평균, 구성종목 수, 기준일 → 종료일, 그 기간의 특이사항 |
| 툴팁 자리 | 범프 차트와 같다([§3.3](#33-툴팁)): **마우스 포인터 왼쪽**에 붙이고, 화면 왼쪽에 자리가 없을 때만 오른쪽으로 넘긴다. 자리는 차트 안이 아니라 **화면**을 기준으로 보고, 상자가 차트 밖으로 나가도 둔다. 좁은 차트에서 안에만 두려 하면 늘 오른쪽으로 밀려 포인터 아래의 캔들을 가린다 |
| 특이사항 | 이 섹터에 속한 종목의 사건([07 §11.2](07-price-ingestion.md#112-특이사항))이 난 기간을 x축 바로 위에 주의색 세모(▲)로 짚는다. 사건 **시작일이 든 기간**에 하나씩 놓고, 건수와 상관없이 표시는 하나다. 시총 축과 무관한 자리라 눈금 없는 보조 축에 얹는다. 범례에는 넣지 않는다 |
| 데이터 없음 | 이 차트 자리에만 안내 문구를 둔다. 드릴다운의 다른 부분은 그대로 그린다 |

- 시가총액은 상장·폐지 같은 가격 외 이유로도 바뀐다. 그 사건이 **언제** 있었는지는 위의 ▲로, **무엇**이었는지는 그 기간 툴팁(날짜·유형·종목, 네 건까지)과 특이사항 패널로 본다. 사건은 `/events?group_code=`([05 §6.3](05-api-spec.md#63-get-events))로 받으며, 시장 단위 사건과 테마 스킴에서는 걸리는 사건이 없다.

## 8. 접근성 및 반응형

- 색상만으로 상승/하락을 구분하지 않는다. 부호와 화살표를 함께 쓴다.
- 범프 차트 선은 색 + 라벨로 식별 가능해야 한다. 26개 섹터에 대해서도 색상만으로는 구분이 불가능하고, 세분류 스킴(48·74개)은 상위 섹터와 색까지 같으므로, **호버 강조와 끝단 라벨을 필수 요소로 취급**한다. 선이 많아 끝단 라벨이 다 들어가지 않으면 섞어 쓰지 않고 생략하며([§3.1](#31-렌더링-규칙)), 더블클릭 강조와 `상위 N` 컨트롤로 줄여 본다.
- 차트 데이터는 `<table>` 형태의 대체 표현을 제공한다(스크린리더 및 CSV 내보내기와 동일 데이터).
- 1280px 미만: 드릴다운 패널이 하단 전체 폭으로 이동.
- 768px 미만: 범프 차트는 표시 섹터 수를 상위 5로 강제하고, 가로 스크롤을 허용한다.
